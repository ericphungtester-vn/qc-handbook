# QC UI Handbook

Tài liệu tra cứu cho QC: tên chuẩn của các UI component (Anh–Việt), checklist "cần test"
cho từng thành phần, mục Trạng thái (states) và bộ dữ liệu test mẫu.

## Xem
- Mở trực tiếp: tải về rồi double-click `qc-ui-handbook.html` (chạy offline, không cần internet).
- Online (nếu bật GitHub Pages): `https://<tài-khoản>.github.io/qc-handbook/`

Trang là 1 file HTML tĩnh, độc lập — không phụ thuộc dịch vụ nào.
